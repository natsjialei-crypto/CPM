# OT侧控制回路性能管理（CPM）应用 —— 功能说明书（0-1版本）

## 一、文档说明

本说明书用于定义 CPM（Control loop Performance Management）应用 0-1 阶段（Demo阶段）的功能范围，作为产品/研发/工艺团队的共同基线。0-1阶段目标：把"回路台账 + 投用/投出状态 + 基础性能可视化"打通，为后续 MVP（多工况判断、分级管理、趋势查询）和回路诊断（故障诊断、优化策略）阶段打好数据与架构基础。

---

## 二、产品定位与范围

对照三阶段路线图（Demo → MVP → 回路诊断），本次功能范围为**第一阶段**：

- 一套以**回路台账**为唯一数据源的**四级架构**（厂区-装置-单元-回路），每个回路有明确的投用/投出状态。
- **性能监测**与**PID参数管理**两条主线功能，彼此独立又通过回路位号关联。
- 按 **GB/T 44693.2-2024**《危险化学品企业工艺平稳性 第2部分：控制回路性能评估与优化技术规范》计算的标准评估/诊断指标。
- 回路间**上下游关联绑定**能力的雏形（先规则化，后数据化）。
- 支撑排查的**趋势图表**能力，尤其是灵活缩放与固定窗口平移。

---

## 三、总体信息架构

依据《回路性能评估统计表》台账字段，确定系统的层级与实体关系：

```
厂区（如 PPA01）
 └─ 装置（如 100区-前处理）
     └─ 工艺单元（如 R101 / V-111 / K191-193，支持多回路挂载同一单元，也支持跨装置的"公辅/总图"类单元）
         └─ 控制回路（回路位号，如 FIC_10130）
             ├─ 基本信息：回路类型（单回路/串级/分程/超驰/前馈…）、控制策略简述、过程类型（流量/压力/液位/温度/成分）
             ├─ 投用状态：自动 / 手动 / 未投用（未开工、间歇使用、设备停用、设备故障、设备备用）
             ├─ 未投用原因类型：工艺 / 控制策略 / 组态错误 / PID参数 / 其他
             ├─ 限位与量程：输出上下限、反积分饱和上下限（ARW_HI/LO）、SP高低限
             └─ 关联关系：上游回路 / 下游回路 / 耦合回路（模块三）
```

**台账即架构**：台账表中的"厂区/装置/单元/回路位号"四列直接作为系统架构树的初始化数据源，避免另建一套主数据；"投用状态""未投用原因类型"直接映射为回路状态机字段。

## 四、功能模块清单

### 模块1：基础架构与回路台账管理

| 功能 | 说明 | 数据来源/依据 |
|---|---|---|
| 台账批量导入 | 支持按现有 Excel 台账（厂区/装置/单元/回路位号/回路类型/控制策略简述等）一键导入，自动生成架构树 | 台账"基本信息""回路情况收集"列 |
| 架构树可视化 | 厂区→装置→单元→回路四级树形/看板展示，支持按厂区、装置、单元筛选 | — |
| 回路档案卡片 | 单回路详情页：基本信息、控制策略简述、投用状态、量程限位、关联回路、历史整定记录一屏呈现 | 台账全字段 |
| 回路增删改与变更审批 | 新增/拆除/停用回路走变更流程，留痕（对应国标"控制回路变更登记台账""变更审批表"要求） | GB/T 44693.2 §5.5 |
| 投用状态字段标准化 | 状态枚举：自动/手动/未投用，未投用再细分：未开工、间歇使用、设备停用、设备故障、设备备用 | 台账"引用"页字典 |
| 未投用/低效原因分类台账 | 原因类型：工艺、控制策略、组态错误、PID参数、其他，作为后续诊断的初筛标签 | 台账"引用"页字典 |

### 模块2：工艺单元与状态管理（开车/停车）

| 功能 | 说明 |
|---|---|
| 单元状态机（两态） | 每个工艺单元维护"开车"/"停车"两种状态，状态变更需操作留痕（时间、操作人、原因） |
| 状态联动评估计算 | 单元处于"停车"状态时，其下所有回路自动**暂停性能评价计算**（对应国标 6.1.4：开停工期间可不进行监控及评价计算），避免开停车误判为低性能 |
| 状态变更历史 | 记录每个单元历次开停车时间区间，供后续按工况切片做趋势分析 |
| 单元-回路继承关系 | 单元停车时，其下回路状态自动置为"未投用-未开工"，开车后按实际投用情况人工/自动确认恢复 |

### 模块3：回路架构与关联绑定（创新点）

| 功能 | 说明 |
|---|---|
| 上下游关系建模 | 在单元维度内，允许为每个回路指定上游回路、下游回路（如串级回路的主副回路、分程回路的耦合对），形成回路拓扑图 |
| 初始绑定规则（工艺角度） | 0-1阶段以**人工/工艺逻辑**为主：依据回路控制策略简述、P&ID 逻辑，由工艺/仪表工程师人工确认上下游及耦合关系，系统提供绑定界面（选择回路A→关系类型→回路B） |
| 内置信号相关性分析工具 | 内置基础数学工具（如皮尔逊相关系数，见 GB/T 44693.2 附录F.7），对候选回路的历史 PV/OP 序列做相关性计算，**辅助**用户发现潜在的耦合/关联回路，输出相关性系数供人工确认，而非自动绑定 |
| 回路架构推荐（半自动） | 系统基于相关性计算结果，向用户推荐"疑似关联回路"清单，用户一键确认/拒绝，逐步沉淀出该单元的回路关系图谱 |
| 单元级回路拓扑图 | 可视化展示某单元下所有回路及其绑定关系，作为后续"多回路联动诊断"的结构基础 |

> 0-1阶段先把"绑定关系"和"相关性计算工具"两件事情做出来并跑通闭环（工艺规则录入 + 数据辅助验证），不要求实现全自动拓扑发现，这是 MVP/诊断阶段的迭代方向。

### 模块4：性能监测模块（按 GB/T 44693.2-2024）

| 功能 | 说明 | 国标依据 |
|---|---|---|
| 数据采集配置 | 按回路过程类型（流量/压力/液位/温度/成分）配置采样周期（≤5s/≤10s/≤20s/≤30s/≤60s） | 附录A |
| 运行数据采集 | 通过 OPC DA/UA 采集 PV、SV、OP、MODE 等实时数据，落历史库 | §6.2.1 |
| 数据质量清洗 | 数据停滞、突变、通信中断识别与清洗，计算"好值率" | 附录F.6 |
| 单回路核心指标计算 | 自控率 Auto、有效自控率 R、准确率 A、快速率 F、稳定率 S、饱和率 Sa | §6.3.1、附录B |
| 回路性能综合评分 P | 按公式 P=[(A·a+F·f+S·s)/(a+f+s)]×R 计算，权重系数 a/f/s 按回路类型（稳定型/慢速型/快速型/逻辑型）选取 | §6.3.1、附录C |
| 回路评估类型标定 | 结合台账"回路类型/控制策略简述"，为每个回路标定稳定型/慢速型/快速型/逻辑型，决定权重取值 | 附录C |
| 性能定级 | 一级(90-100)/二级(80-90)/三级(70-80)/四级(60-70)/五级(0-60)，五级需醒目提示 | 附录D |
| 数据异常/自控率过低强制定级 | 数据异常或统计时段自控率低于阈值的回路，直接判定为五级 | §6.3.3 |
| 装置/单元/企业级综合指标 | 实时自控率、平均自控率、平稳率、性能评分的加权汇总（可按模块3的回路重要性权重加权） | §6.4、附录E |
| 关键绩效目标线 | 平均自控率≥95%、平稳率≥95%、性能评分≥80% 等目标值对比展示 | 附录E.1 |
| 历史趋势与多工况判断预留位 | 0-1阶段先做单点/日级评估结果留存，为 MVP 阶段"多工况判断""趋势查询"预留数据结构 | — |

### 模块5：趋势图表模块

趋势图表是回路详情页、单元健康度下钻页的核心组件，承担"从指标异常到原始波形"的最后一公里。评估指标（自控率/性能评分）和诊断指标（振荡率/黏滞系数）告诉用户"哪个回路有问题"，趋势图表要让用户**一眼看出问题长什么样**（震荡、超调、饱和、滞后跟踪等），并支持工程师像操作趋势曲线一样自由地"翻找"历史波形。本模块**重点强调交互灵活性**，尤其是缩放与固定窗口平移两类核心操作。

**5.1 灵活缩放（Zoom In / Out）**

| 需求点 | 说明 |
|---|---|
| 任意区间框选缩放 | 鼠标/触屏在图表上拖拽框选任意时间区间，即可放大查看该区间细节，不限定为固定倍数 |
| 连续缩放层级 | 支持从"月/周"粗粒度逐级缩放到"分钟级"细粒度，缩放过程数据自动按采样周期重新拉取，不因缩放丢失细节或卡顿 |
| 缩放后回退 | 提供"缩小一级 / 复位到默认视图"按钮，支持多级缩放历史回退（类似浏览器前进后退） |
| 双图联动缩放（可选） | 若同屏展示多个回路（如上下游关联回路对比），支持缩放动作在多图间同步，保证时间轴对齐 |
| 缩放不丢失标注 | 缩放/平移过程中，异常标注点（震荡区间、饱和区间、参数变更时刻）始终保持在正确时间位置上 |

**5.2 固定窗口平移（1小时窗口，左右滑动查看）—— 主推交互模式**

| 需求点 | 说明 |
|---|---|
| 默认窗口宽度 | 打开趋势图表默认展示**最近1小时**数据，窗口宽度可配置（15min/30min/**1h（默认）**/4h/24h），但"1小时固定窗口+左右平移"为主推模式 |
| 窗口宽度锁定 | 用户选定窗口宽度（如1h）后，窗口宽度保持固定，滑动时只改变时间起点，不改变跨度，保证前后画面数据密度一致、便于视觉比对 |
| 左右滑动方式 | 支持三种等效操作，覆盖桌面与触屏场景：① 图表下方滑动条（scrollbar）拖动；② 图表区域左右滑手势（触屏/触控板）；③ 左右箭头按钮，按一次平移固定步长 |
| 平移步长可配 | 默认平移步长=窗口宽度的50%（即1h窗口，一次平移30min），避免画面跳变过大导致上下文丢失；用户可自定义步长 |
| 快捷跳转 | 提供"跳转到指定时间""回到最新（Live）""上一个异常点/下一个异常点"快捷按钮，异常点跳转直接定位到该异常发生时刻所在的1h窗口 |
| 键盘快捷键（桌面端） | 左右方向键=平移窗口；+/-=缩放；Home=回到最新 |
| 实时追随模式 | 查看"最新"窗口时，新数据到达自动向右滚动追加；一旦用户手动向左滑动查看历史，自动退出追随模式，避免打断排查 |

> 设计原则：**"固定窗口平移"用于逐段人工排查（横向对比不同时段同一回路的波形形态），"自由缩放"用于定位到具体异常点后的细节钻取**，两种模式共存、可随时切换，不互斥。

**5.3 图表内容与叠加能力**

| 功能 | 说明 |
|---|---|
| 多曲线叠加 | 同图叠加 PV（过程测量值）、SP（设定值）、OP（输出值），MODE（自动/手动）以背景色块或独立轨道展示 |
| 曲线显隐控制 | 图例可点击显隐单条曲线，聚焦排查 |
| 双Y轴 | PV/SP 与 OP 单位/量程不同时，支持左右双Y轴分别标定 |
| 限位参考线 | 叠加显示输出上下限、SP高低限、反积分饱和上下限，直观判断是否触限 |
| 异常区间高亮 | 振荡区间、饱和区间、手动介入区间以半透明色带标注在时间轴上，与诊断指标计算结果联动 |
| 参数变更标记 | PID参数整定时刻在时间轴上打竖线标记，点击可查看变更前后参数详情 |
| 数值悬浮提示 | 鼠标悬停/触屏长按显示该时刻精确数值（PV/SP/OP/MODE） |
| 多回路对比视图 | 支持将模块3绑定的上下游/关联回路的趋势图并排或叠加展示，观察联动关系 |

**5.4 与其他模块的联动**

| 触发点 | 联动效果 |
|---|---|
| 单元健康度看板下钻 | 点击异常回路 → 自动打开该回路趋势图，默认窗口定位到最近一次异常发生时段 |
| 诊断指标结果 | 点击"振荡率异常"等诊断标签 → 趋势图自动缩放至对应异常区间并高亮 |
| PID参数变更记录 | 点击某次整定记录 → 趋势图自动平移到该整定时刻前后1h窗口，便于对比整定前后效果 |
| 回路关联绑定 | 在拓扑图中选中一对上下游回路 → 触发"多回路对比视图" |

**5.5 趋势图表非功能性需求**

| 类别 | 要求 |
|---|---|
| 性能 | 单条曲线1h窗口内数据点渲染流畅，缩放/平移操作响应延迟 < 300ms |
| 数据抽稀 | 大跨度（如24h/7天）展示时后端做抽稀/降采样，缩放到细粒度时自动请求原始高频数据 |
| 移动端适配 | 触屏手势（双指缩放、单指滑动）与桌面端鼠标操作体验一致 |
| 离线/断点提示 | 数据缺失/通信中断区间在曲线上以断线或灰色区域标出，不做虚假插值连线 |

### 模块6：PID参数管理模块

| 功能 | 说明 |
|---|---|
| 当前参数一览 | 展示每个回路当前 P/I/D、PV Filter、输出限位、反积分饱和限位、SP限位、阀门当前开度 |
| 整定前后参数对比 | 沿用台账"优化前(P/I/D/PV Filter)—优化后(P2/I2/D2/PV Filter2/λ)"结构，一屏对比 |
| 参数变更记录（台账） | 每次整定留存：整定时间、整定人、优化过程分析、优化后投用情况、是否消除震荡、备注（对应国标"PID参数调整记录""维护日志"） |
| 参数变更审批流 | 涉及组态变动的参数修改走变更管理流程，留痕可追溯 |
| 参数与性能指标联动展示 | 在回路档案页同时展示"当前参数版本"与"该版本对应的性能评分/定级"，便于评估整定效果 |
| 备用参数保存 | 支持保存一组"备用/回退参数"，便于整定失败快速回退（国标§8.3要求留存备用PID参数） |

### 模块7：性能诊断模块

| 功能 | 说明 | 国标依据 |
|---|---|---|
| 振荡率 Osc | 识别 PID 参数不当、输出黏滞导致的周期性振荡 | 附录F.1 |
| 黏滞系数 St | 识别阀门黏滞、内漏问题 | 附录F.2 |
| 饱和率 Sa | 识别执行器长期处于限位的问题 | 附录F.3 |
| 稳态时间 T | 识别响应速度/PID参数不合适问题 | 附录F.4 |
| 输出值行程指数 Trip | 识别阀门磨损风险 | 附录F.5 |
| 好值率 Qu | 识别通信/仪表故障导致的数据异常 | 附录F.6 |
| 相关性指数 Sim | 识别回路间耦合情况（与模块3绑定工具复用同一计算能力） | 附录F.7 |
| 多指标综合诊断 | 结合以上指标+台账人工标注的"未投用原因类型"（仪表/执行器/控制策略/PID参数/组态/数据异常），给出初步故障归类，供人工确认 | 附录F.8、GB第7章 |
| 故障类型标签库 | 仪表故障、执行器故障、控制策略不合理、PID参数不合理、其他参数设置不合理、数据异常六大类，作为诊断结果标签 | GB第7章 |

### 模块8：单元健康度看板与下钻分析

| 功能 | 说明 |
|---|---|
| 单元健康度总览卡片 | 按厂区/装置/单元三级展示：自控率、性能评分、性能定级分布（一至五级回路数量占比） |
| 异常直观提示 | 五级/四级回路、饱和率过高、振荡率过高等异常项以颜色/角标高亮，单元卡片汇总异常回路数 |
| 一键下钻 | 从单元健康度卡片点击 → 该单元回路列表（按评分排序）→ 具体回路详情页（评估指标+诊断指标+PID参数+趋势图表+关联回路一屏展示） |
| 排行榜 | 装置/企业级"性能评分较差TOP10""自控率较差TOP10"，对应国标评估报告要求 |
| 开停车状态过滤 | 看板默认剔除"停车"单元及其回路，避免误报 |

## 五、后续迭代方向（不在0-1范围内）

| 阶段 | 方向 |
|---|---|
| MVP | 多工况判断、回路分级管理自动化、跨回路/跨装置趋势查询、性能可视化报表 |
| 回路诊断 | 故障诊断指标自动归因升级、优化策略推荐、影响分析、优化效果对比与跟踪 |
